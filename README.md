## ⚙️ Features
- Authentication (JWT)
- Product & Inventory Management
- Order Processing (COD, Stripe, Razorpay)
- Admin Dashboard for full control
- Email notifications (Nodemailer)

## 🧱 Tech Stack
React, Node.js, Express, MongoDB, Stripe, Razorpay, Cloudinary
